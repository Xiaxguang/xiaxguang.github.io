Account

帳號與資料保存

正式帳號與 UID 是保存 T-LO 實況星域進度的重要依據。若你需要跨裝置遊玩、查詢卡牌、確認獎勵或回報儲值支持問題，請先確認自己使用的是正式帳號。

最後更新：2026年7月13日

Saved Data

會保存哪些資料

  • 玩家 UID、登入識別與基本帳號狀態。
  • 卡牌取得紀錄、卡牌收藏、星等、技能與養成狀態。
  • 抽卡紀錄、活動紀錄、禮包碼紀錄與獎勵發放紀錄。
  • 星域戰場、連線討伐、遠征、世界 BOSS 與星潮沙盤戰進度。
  • 人氣、打賞、行動力、體力、通行證分數與其他遊戲內資源。
  • 儲值、支持、發放確認與客服處理紀錄。
Device

跨裝置與瀏覽器

使用同一正式帳號登入時，系統會依照帳號資料讀取遊戲進度。若只使用訪客或暫存資料，關閉瀏覽器、清除資料或更換裝置後可能無法恢復。

建議玩家記錄自己的 UID，並避免把登入資料提供給不明來源。

資料查詢流程

需要客服協助時，請提供足夠資訊，讓管理員能確認問題範圍。

  1. 確認玩家 UID、帳號名稱或可辨識資料。
  2. 記錄發生時間、操作流程與問題頁面。
  3. 準備截圖、錄影或錯誤訊息。
  4. 若與儲值或支持有關，提供需求內容、確認時間與相關截圖。
  5. 透過聯絡方式提出查詢，等待管理員確認身分與資料範圍。
Correction

資料更正

若帳號資料、獎勵紀錄或儲值支持紀錄顯示異常，可提供證明資料申請查詢與修正。

Deletion

資料刪除

若希望刪除與自己相關的資料，可透過聯絡方式提出需求。實際處理需確認身分與資料範圍。

Security

帳號安全

請勿與他人共用帳號，避免站外交易、代儲、代抽或提供驗證資訊給不明來源。
