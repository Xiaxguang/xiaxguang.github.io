星域地圖玩法

星潮沙盤戰是卡牌式地圖玩法。玩家選擇陣營後會從外圍生成總部，沿著相鄰地塊鋪路、佔領資源地、建立分公司，最後朝中央年度盛典推進。

最後更新：2026年7月13日

Tile Types

地塊類型

  • 玩家總部：玩家的起點，可重新組團、休息與查看營運狀態。
  • 一般地塊：用於鋪路、擴張與連接更高等級區域。
  • 資源地塊：LV3 以上且帶有資源類型的地塊，佔領後可產出人氣或打賞。
  • 裂縫與不可通行區域：地圖中不可通行的阻隔，需從可行路徑繞過。
  • 年度盛典：中央核心目標，需陣營共同推進。
Levels

LV1 至 LV10

地塊有 LV1 至 LV10。等級越高，通常需要更高粉絲戰力與更謹慎的體力管理。遊戲內會在地塊資訊中顯示等級、種類、預估敵方戰力、預估產出與佔領後每小時產出。

LV1-LV2適合早期鋪路與熟悉操作。
LV3 以上可能出現人氣或打賞資源地。
LV10年度盛典周邊，屬於高壓推進區。
How To Read

如何查看地塊資訊

  1. 進入星潮沙盤戰，等待地圖載入並定位總部。
  2. 點擊總部可回到玩家主城視角與總部管理資訊。
  3. 點擊未佔領地塊，查看地塊等級、地塊種類、預估敵方戰力與攻打行動力。
  4. 點擊資源地塊，查看預估產出與佔領後每小時產出。
  5. 點擊已佔領地塊，可查看目前產出、可領取資源、分公司狀態與是否可快閃。
Road

鋪路與擴張

攻打相鄰地塊是推進核心。若地塊尚未連接，需先佔領附近格子建立路線。

Limit

持有格上限

初始持有格有上限。公司擴編每級提高持有格上限，避免擴張過程太快卡住。

Branch

分公司

公司擴編 LV1 後，可在符合條件的已佔領地塊建造分公司，作為巡演團體休息據點。
